Flamboyan 4

Kebijakan Privasi

27 November 2026

Portal Flamboyan 4 (flamboyan4.web.id) dikelola untuk informasi, kegiatan, dokumentasi, dan administrasi warga Flamboyan 4.

Data yang diproses

Portal dapat memproses identitas akun, nama warga, nomor rumah, data administrasi dan keuangan, foto profil, dokumentasi, komentar, tanda suka, tag warga, serta informasi teknis yang diperlukan untuk menjalankan layanan. Akses data administrasi mengikuti hak akses akun.

Integrasi Google Drive

Integrasi Google Drive menggunakan otorisasi akun penyimpanan pengelola. Data yang digunakan untuk fitur dokumentasi mencakup file foto dan video, folder album, nama file, ID file dan informasi terkait file. Portal menggunakan akses tersebut untuk membaca, menampilkan, menyimpan, mengatur, memindahkan, dan menghapus dokumentasi sesuai tindakan pengguna atau pengelola yang berwenang. Warga tidak perlu menghubungkan Google Drive pribadi untuk mengunggah foto melalui portal.

Token otorisasi digunakan oleh backend untuk berkomunikasi dengan Google API. Foto profil disimpan terpisah dari dokumentasi kegiatan. Penyimpanan dan layanan teknis melibatkan Google Drive dan Cloudflare.

Penggunaan dan keterbukaan informasi

Data digunakan untuk menyediakan fitur portal, pengelolaan kegiatan, administrasi warga dan keamanan layanan. Dokumentasi yang dipublikasikan dapat terlihat oleh pengunjung umum; file yang dibagikan melalui tautan publik dapat diakses oleh pemegang tautan. Jangan mengunggah materi pribadi atau sensitif tanpa izin yang sesuai.

Data yang diperoleh melalui Google API digunakan untuk fitur dokumentasi yang dijelaskan di atas, bukan untuk penjualan data, iklan personal, atau pelatihan model AI umum. Penggunaan dan pemindahan informasi dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Penyimpanan, penghapusan dan kendali data

Dokumentasi dan catatan disimpan untuk kebutuhan operasional dan arsip warga. Pengguna dapat meminta koreksi, penyembunyian atau penghapusan informasi melalui pengelola. Permintaan ditangani dengan mempertimbangkan kebutuhan arsip, hak pihak lain dan kewajiban yang berlaku. Pemilik akun Google dapat mencabut akses aplikasi melalui pengaturan keamanan akun Google; pencabutan dapat menghentikan fungsi dokumentasi.

Kontak

Pertanyaan dan permintaan terkait privasi dapat disampaikan kepada pengelola Flamboyan 4 melalui hjbenalu@gmail.com.
